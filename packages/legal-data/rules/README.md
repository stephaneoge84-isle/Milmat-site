# Règles juridiques

Les premières règles sont codées dans packages/legal-engine/src/rules pour permettre le bootstrap. Elles seront migrées vers des données versionnées (JSON/DB) dès que le schéma de persistance sera choisi.

Toute règle non suffisamment vérifiée doit rester TODO_REVIEW et ne doit pas produire de conclusion ACTIVE.
